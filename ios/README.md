# ios

## Overview
iOS client subtree for `rekordbox-collection-manager`, containing the `RekordboxCompanion` SwiftUI Xcode project (`iOS 17.0`, `Swift 5.0`) that provides offline SQLite caching, live DJ set tracking, track/playlist/MyTag management, and Turso remote changelog synchronization.

## Subdirectories & Boundaries
- `RekordboxCompanion`: [RekordboxCompanion](./RekordboxCompanion/README.md) - Xcode project root (`RekordboxCompanion.xcodeproj`) and SwiftUI application package (`RekordboxCompanion/`), encompassing `Config`, `Models`, `Services`, and `Views`.
