# Services

## Overview
Core application state, local SQLite persistence, and remote Turso libSQL synchronization services for the `RekordboxCompanion` iOS target. `AppState` coordinates reactive UI state and local-first mutations backed by `LocalDatabase` (`rekordbox_companion.db`), while `TursoSyncService` pushes queued changelog events and pulls collection, history session, and event status updates over Turso's HTTP `/v2/pipeline` endpoint.

## Invariants
- `AppState.sync()` is `@MainActor`-isolated, guards `!isSyncing` to prevent overlapping sync runs, clears `syncErrorMessage`, runs `pushPendingEvents -> pullLatestCollection -> pullEventStatuses -> loadFromCache` sequentially, and resets `isSyncing = false` on exit (`[AppState.swift:AppState.sync()]`).
- `AppState.pendingCount` computes `changelogEvents.filter { $0.isPending }.count`, and `loadFromCache()` loads `activeSessionTracks` only when `activeSession != nil` (otherwise `[]`) alongside up to 10 `recentSessions` (`[AppState.swift:AppState.pendingCount]`, `[AppState.swift:AppState.loadFromCache()]`).
- `AppState` guards `activeSession != nil` in `addTrackToActiveSession`, `removeTrackFromActiveSession`, `reorderActiveSession`, `endActiveSession`, and `discardActiveSession`, keeping `activeSession?.trackCount == activeSessionTracks.count` on track additions/removals (`[AppState.swift:AppState.addTrackToActiveSession(track:)]`, `[AppState.swift:AppState.removeTrackFromActiveSession(liveTrackId:)]`).
- `AppState` clamps `djPlayCount` with `max(0, ...)` in `adjustPlayCount` (local + payload) and in the `UPDATE_TRACK` payload of `updateTrackMetadata`, and includes `"parent_id"` in `CREATE_PLAYLIST` payloads only when `parentId != nil` (`[AppState.swift:AppState.adjustPlayCount(track:delta:)]`, `[AppState.swift:AppState.updateTrackMetadata(track:title:comment:rating:djPlayCount:tagIds:)]`, `[AppState.swift:AppState.createPlaylist(name:parentId:)]`).
- `LocalDatabase.shared` enforces singleton initialization via `private init()`, requires `FileManager.default` `.documentDirectory` (else `fatalError`) for `rekordbox_companion.db`, creates 9 tables (`tracks`, `playlists`, `playlist_tracks`, `tags`, `track_tags`, `changelog_events`, `live_sessions`, `live_session_tracks`, `history_sessions`) and 3 indexes (`idx_lst_session`, `idx_hs_loc`, `idx_hs_collab`) without SQLite `FOREIGN KEY` constraints, and removes `DISCARDED` sessions and orphaned `live_session_tracks` on startup (`[LocalDatabase.swift:LocalDatabase.shared]`, `[LocalDatabase.swift:openDatabase()]`, `[LocalDatabase.swift:createTables()]`).
- `LocalDatabase` filters out streaming tracks on `upsertTracks(_:)`, deletes streaming/hardcoded IDs on `pruneStreamingTracks()`, excludes streaming tracks in `getAllTracks()`, `getTracksForPlaylist(playlistId:)`, `getTrackCountForPlaylist(playlistId:)`, `getTrackCountForTag(tagId:)`, and `getTracksForTag(tagId:)`, and clamps `dj_play_count` with `max(0, ...)` on collection writes/reads (though `getTrack(byId:)`, `getTrackIdsForTag(tagId:)`, `getTrackIdsForPlaylist(playlistId:)`, and `getLiveSessionTracks(sessionId:)` do not apply streaming filters, and `getLiveSessionTracks(sessionId:)` does not clamp `djPlayCount`) (`[LocalDatabase.swift:pruneStreamingTracks()]`, `[LocalDatabase.swift:upsertTracks(_:)]`, `[LocalDatabase.swift:getAllTracks()]`).
- `LocalDatabase` batch upserts run `INSERT OR REPLACE` inside `BEGIN TRANSACTION ... COMMIT`, `replacePlaylistTracks` and `replaceTrackTags` atomically `DELETE` + `INSERT` in transactions, `upsertChangelogEvent` preserves `action`/`payload`/`created_at` on conflict while updating `status`/`processed_at`/`error_message`, `getAllChangelogEvents()` caps at `LIMIT 50` ordered `created_at DESC`, and `clearProcessedChangelogEvents()` deletes `'PROCESSED'` and `'FAILED'` rows (`[LocalDatabase.swift:replacePlaylistTracks(_:)]`, `[LocalDatabase.swift:upsertChangelogEvent(id:action:payload:status:createdAt:processedAt:errorMessage:)]`, `[LocalDatabase.swift:getAllChangelogEvents()]`, `[LocalDatabase.swift:clearProcessedChangelogEvents()]`).
- `LocalDatabase` live sessions default `status = 'ACTIVE'` and `increment_play_counts = 1`, assign sequential `track_no = COALESCE(MAX(track_no), 0) + 1`, re-sequence remaining rows `1..N` transactionally on track removal, enqueue `'CREATE_HISTORY_SESSION'` with fallback name `'HISTORY <YYYY-MM-DD>'` on completion, and merge `getPastLocations()` / `getPastCollaborators()` from up to 50 recent completed/history rows with hardcoded default venue/collaborator lists (`[LocalDatabase.swift:startLiveSession(name:dateCreated:location:collaborators:startedAt:)]`, `[LocalDatabase.swift:addTrackToLiveSession(sessionId:trackId:playedAt:)]`, `[LocalDatabase.swift:removeTrackFromLiveSession(sessionId:liveTrackId:)]`, `[LocalDatabase.swift:endLiveSession(sessionId:incrementPlayCounts:)]`, `[LocalDatabase.swift:getPastLocations()]`).
- `TursoSyncService.shared` uses `private init()`, rewrites `libsql://` to `https://` and appends `/v2/pipeline` in `endpointURL`, sends `Authorization: Bearer <token>` and `Content-Type: application/json`, appends `["type": "close"]` to every pipeline request, requires HTTP 200 with a JSON `"results"` array free of `"type": "error"` items, and validates minimum column counts per query (`[TursoSyncService.swift:TursoSyncService.init()]`, `[TursoSyncService.swift:TursoSyncService.endpointURL]`, `[TursoSyncService.swift:TursoSyncService.executePipeline(requests:)]`, `[TursoSyncService.swift:TursoSyncService.pullLatestCollection()]`).

## Side Effects
- `AppState` mutates `@Observable` properties, reads/writes `LocalDatabase.shared`, emits stdout error logs in `sync()`, and launches unstructured `Task` background pushes (`triggerBackgroundPush()`) after track/playlist edits and live session completion (`[AppState.swift:AppState.sync()]`, `[AppState.swift:AppState.triggerBackgroundPush()]`, `[AppState.swift:AppState.updateTrackMetadata(track:title:comment:rating:djPlayCount:tagIds:)]`, `[AppState.swift:AppState.endActiveSession(incrementPlayCounts:)]`).
- `LocalDatabase` opens/creates `rekordbox_companion.db` in `.documentDirectory`, closes the SQLite handle in `deinit`, runs startup DDL and `DISCARDED`/streaming cleanups, and performs SQLite inserts, updates, replacements, and deletions across all 9 local tables (`[LocalDatabase.swift:openDatabase()]`, `[LocalDatabase.swift:deinit]`, `[LocalDatabase.swift:createTables()]`, `[LocalDatabase.swift:pruneStreamingTracks()]`).
- `TursoSyncService` executes HTTPS POST requests via `URLSession.shared.data(for:)` against Turso `/v2/pipeline` (including remote `CREATE TABLE IF NOT EXISTS history_sessions` and `INSERT OR IGNORE INTO changelog_events`), writes pulled records to `LocalDatabase.shared`, and spawns a background `Task` in `pullLatestCollection()` to pull history sessions and event statuses (`[TursoSyncService.swift:TursoSyncService.executePipeline(requests:)]`, `[TursoSyncService.swift:TursoSyncService.pullLatestCollection()]`, `[TursoSyncService.swift:TursoSyncService.pullHistorySessions()]`, `[TursoSyncService.swift:TursoSyncService.pushPendingEvents()]`).
