# Views

## Overview
SwiftUI view layer for `RekordboxCompanion`, providing tab navigation (`MainTabView`), track browsing/filtering/metadata editing (`TracksView`, `TrackDetailSheet`), hierarchical playlist management (`PlaylistsView`, `PlaylistDetailView`), MyTag browsing (`TagsView`), live DJ set tracking with Camelot key/BPM matching (`LiveSetView`), and Turso sync queue diagnostics and configuration (`SyncQueueView`).

## Interface
- `struct MainTabView: View` — Root `TabView` hosting `TracksView`, `PlaylistsView`, `LiveSetView`, `TagsView`, and `SyncQueueView` with `@Environment(AppState.self)` (`[MainTabView.swift:MainTabView]`, `[MainTabView.swift:MainTabView.body]`).
- `struct TracksView: View` — Searchable, sortable, filterable track list (`categoryFolders`, `availableKeys`, `activeFilterCount`, `filteredTracks`, `resetFilters()`, `body`) (`[TracksView.swift:TracksView]`, `[TracksView.swift:TracksView.filteredTracks]`, `[TracksView.swift:TracksView.resetFilters]`).
- `enum TrackSortOption: String, CaseIterable, Identifiable`, `enum PlayStatusFilter: String, CaseIterable, Identifiable`, and `enum BpmFilterOption: String, CaseIterable, Identifiable` — Sort and filter option enums for `TracksView` and `TrackFilterSheet` (`[TracksView.swift:TrackSortOption]`, `[TracksView.swift:PlayStatusFilter]`, `[TracksView.swift:BpmFilterOption]`).
- `struct TrackFilterSheet: View` and `struct TrackRow: View` — Filter/sort modal bindings (`selectedSortOption`, `playStatusFilter`, `bpmRangeFilter`, `selectedKey`, `selectedTagId`, `availableKeys`, `categoryFolders`, `onReset`) and compact track list row (`[TracksView.swift:TrackFilterSheet]`, `[TracksView.swift:TrackRow]`).
- `struct FlowLayout: Layout`, `struct ChipView: View`, and `struct TrackDetailSheet: View` — Wrapping chip layout (`spacing`, `sizeThatFits(proposal:subviews:cache:)`, `placeSubviews(in:proposal:subviews:cache:)`), removable chip component (`title`, `subtitle?`, `systemImage`, `tintColor`, `onRemove`), and track detail/playlist/MyTag editor (`init(track:)`, `categoryFolders`, `allRegularPlaylists`, `selectedPlaylistsList`, `availablePlaylists`, `matchingPlaylists`, `allAvailableTags`, `selectedTagsList`, `matchingTags`, `categoryName(for:)`) (`[TrackDetailSheet.swift:FlowLayout]`, `[TrackDetailSheet.swift:ChipView]`, `[TrackDetailSheet.swift:TrackDetailSheet]`).
- `struct PlaylistsView: View`, `struct PlaylistRowItem: View`, `struct CreatePlaylistSheet: View`, and `struct AddToPlaylistSheet: View` — Recursive folder/playlist tree (`rootPlaylists`, `childPlaylists`), playlist creation modal, and single-track playlist assignment sheet (`regularPlaylists`) (`[PlaylistsView.swift:PlaylistsView]`, `[PlaylistsView.swift:PlaylistRowItem]`, `[PlaylistsView.swift:CreatePlaylistSheet]`, `[PlaylistsView.swift:AddToPlaylistSheet]`).
- `struct PlaylistDetailView: View` and `struct AddTracksMultiSelectSheet: View` — Playlist track list (`playlist`, `filteredTracks`) with reordering/removal and multi-select track adder (`playlist`, `onDone`, `availableTracks`) (`[PlaylistDetailView.swift:PlaylistDetailView]`, `[PlaylistDetailView.swift:AddTracksMultiSelectSheet]`).
- `struct TagsView: View` and `struct TagTracksListView: View` — Category-grouped MyTag browser (`categoryFolders`, `filteredChildTags(for:)`, `totalMatchingTagsCount`) and per-tag track list (`tag`, `filteredTracks`) (`[TagsView.swift:TagsView]`, `[TagsView.swift:TagTracksListView]`).
- `struct LiveSetView: View`, `struct StartLiveSetSheet: View`, and `struct EndLiveSetSheet: View` — Active/standby live DJ set workspace (`lastPlayedTrack`, `quickSearchResults`, `displayedSessionTracks`, `body`), session starter sheet with `FocusedField` (`location`, `collaborators`) and location/collaborator autocomplete, and session completion/discard sheet (`[LiveSetView.swift:LiveSetView]`, `[LiveSetView.swift:StartLiveSetSheet]`, `[LiveSetView.swift:StartLiveSetSheet.FocusedField]`, `[LiveSetView.swift:EndLiveSetSheet]`).
- `struct SyncQueueView: View` and `struct SettingsSheet: View` — Turso sync diagnostics, changelog queue viewer/manager, and Turso endpoint/token settings modal (`[SyncQueueView.swift:SyncQueueView]`, `[SyncQueueView.swift:SettingsSheet]`).

## Invariants
- `MainTabView` displays `"record.circle.fill"` with `"LIVE"` badge when `appState.activeSession != nil` (else `"record.circle"` and no badge), displays `"\(appState.pendingCount)"` badge on the Sync tab when `appState.pendingCount > 0`, and applies `.tint(.blue)` (`[MainTabView.swift:MainTabView.body]`).
- `TracksView.filteredTracks` excludes streaming tracks (`!$0.isStreaming`), searches case-insensitively across `title`, `artist`, `album`, and `keyName`, enforces `PlayStatusFilter` (`djPlayCount > 0` or `== 0`), `BpmFilterOption` (`< 120` excluding `0`, `120...125`, `125<..130`, `> 130`), case-insensitive `selectedKey`, and `selectedTagId`, and sorts deterministically by `TrackSortOption` (`[TracksView.swift:TracksView.filteredTracks]`).
- `TracksView.activeFilterCount` counts only active `playStatusFilter`, `bpmRangeFilter`, `selectedKey`, and `selectedTagId` (`0...4`), `resetFilters()` preserves `searchText`, `TrackRow` renders play count pill only when `djPlayCount > 0` and key badge only when `!keyName.isEmpty`, and `TrackDetailSheet` / `TracksView` restrict MyTag categories to root-level `"Genre"` and `"Style"` folders (`parentId == nil || parentId == "root" || parentId == "0" || parentId == ""`) sorted by `seq` (`[TracksView.swift:TracksView.activeFilterCount]`, `[TracksView.swift:TracksView.categoryFolders]`, `[TracksView.swift:TrackRow.body]`, `[TrackDetailSheet.swift:TrackDetailSheet.categoryFolders]`).
- `TrackDetailSheet` excludes folder (`isFolder`) and smart (`isSmart`) playlists from assignable playlists, caps search dropdowns at 6 items, auto-adds on submit only when matching count is `1`, expands bottom scroll padding from `32` to `340` when focused, and commits tag/playlist diffs only on `"Done"` (`updateTrackMetadata` only if `selectedTagIds != initialTagIds`, preserving existing `title`, `comment`, `rating`, `djPlayCount`) (`[TrackDetailSheet.swift:TrackDetailSheet.allRegularPlaylists]`, `[TrackDetailSheet.swift:TrackDetailSheet.matchingPlaylists]`, `[TrackDetailSheet.swift:TrackDetailSheet.matchingTags]`, `[TrackDetailSheet.swift:TrackDetailSheet.body]`).
- `FlowLayout` wraps subviews to a new row only when `x + size.width > maxX` and `x > minX` (at least one subview per row), and `ChipView` renders `subtitle` with `"›"` only when non-nil and non-empty (`[TrackDetailSheet.swift:FlowLayout.sizeThatFits]`, `[TrackDetailSheet.swift:FlowLayout.placeSubviews]`, `[TrackDetailSheet.swift:ChipView.body]`).
- `PlaylistsView` displays root playlists (`parentId == nil`, `"root"`, `"0"`, or `""`), `PlaylistRowItem` renders folders as recursive `DisclosureGroup`s and leaf playlists as `NavigationLink`s (`gearshape.fill` for smart playlists), `CreatePlaylistSheet` disables `"Create"` when trimmed name is empty, and `AddToPlaylistSheet` excludes folder playlists (`!$0.isFolder`) (`[PlaylistsView.swift:PlaylistsView.rootPlaylists]`, `[PlaylistsView.swift:PlaylistRowItem.body]`, `[PlaylistsView.swift:CreatePlaylistSheet.body]`, `[PlaylistsView.swift:AddToPlaylistSheet.regularPlaylists]`).
- `PlaylistDetailView` treats smart playlists (`playlist.isSmart`) as read-only (hides `EditButton()`, `+` add button, swipe delete, and `.onMove`), allows `.onMove` and `EditButton()` only when `!playlist.isSmart && searchText.isEmpty && !tracks.isEmpty`, and `AddTracksMultiSelectSheet` excludes streaming tracks and disables `"Add"` while `selectedTrackIds.isEmpty` (`[PlaylistDetailView.swift:PlaylistDetailView.body]`, `[PlaylistDetailView.swift:AddTracksMultiSelectSheet.availableTracks]`, `[PlaylistDetailView.swift:AddTracksMultiSelectSheet.body]`).
- `TagsView` restricts sections to root `"Genre"` and `"Style"` tags, hides empty sections, swaps refresh button for `ProgressView()` during `appState.isSyncing`, and `TagTracksListView` filters case-insensitively across `title`, `artist`, `genre`, `album`, and `keyName` (`[TagsView.swift:TagsView.categoryFolders]`, `[TagsView.swift:TagsView.body]`, `[TagsView.swift:TagTracksListView.filteredTracks]`).
- `LiveSetView` switches between `activeSessionView` (`appState.activeSession != nil`) and `standbyView` (showing up to 5 `recentSessions`), computes Camelot compatibility (`1...12` + `A`/`B` with wrap-around `12<->1`, same key, relative A/B, and `±1`), limits `quickSearchResults` to non-streaming tracks and 40 results only when search or a filter (`±4 BPM`, `Key match`) is active, reverses `displayedSessionTracks` by default (`isReverseOrder = true`), and reorders against unreversed `appState.activeSessionTracks` (`[LiveSetView.swift:LiveSetView.body]`, `[LiveSetView.swift:LiveSetView.getCompatibleKeys(for:)]`, `[LiveSetView.swift:LiveSetView.quickSearchResults]`, `[LiveSetView.swift:LiveSetView.displayedSessionTracks]`, `[LiveSetView.swift:LiveSetView.playedTracksListSection(session:)]`).
- `StartLiveSetSheet` formats `previewSessionName` as `"HISTORY yyyy-MM-dd"` with optional `"@ <location>"` and `"w <collaborators>"`, normalizes empty trimmed `location`/`collaborators` to `nil`, caps location/collaborator autocomplete dropdowns at 5 rows when focused, and deduplicates DJs case-insensitively; `EndLiveSetSheet` defaults `incrementPlayCounts` to `true` and renders only when `appState.activeSession != nil` (`[LiveSetView.swift:StartLiveSetSheet.previewSessionName]`, `[LiveSetView.swift:StartLiveSetSheet.filteredLocations]`, `[LiveSetView.swift:StartLiveSetSheet.filteredCollaborators]`, `[LiveSetView.swift:EndLiveSetSheet.body]`).
- `SyncQueueView` displays green `"Connected to Turso"` when `syncErrorMessage == nil` else red `"Error"`, hides `"Clear Completed"` unless non-pending events exist, disables sync button while `appState.isSyncing`, and `SettingsSheet` masks `token` in `SecureField` and disables autocapitalization/autocorrection on `dbURL` (`[SyncQueueView.swift:SyncQueueView.body]`, `[SyncQueueView.swift:SettingsSheet]`).

## Side Effects
- Views read synchronously from `LocalDatabase.shared` during initialization/body evaluation/appearance (`getTagIds`, `getPlaylistIds`, `getTrackIdsForTag`, `getTracksForPlaylist`, `getTrackCountForPlaylist`, `getTrackCountForTag`, `getTracksForTag`) (`[TrackDetailSheet.swift:TrackDetailSheet.init(track:)]`, `[TracksView.swift:TracksView.filteredTracks]`, `[PlaylistDetailView.swift:PlaylistDetailView.loadPlaylistTracks]`, `[PlaylistsView.swift:PlaylistRowItem.body]`, `[PlaylistsView.swift:AddToPlaylistSheet.body]`, `[TagsView.swift:TagsView.body]`, `[TagsView.swift:TagTracksListView.loadTracks]`).
- User actions mutate `AppState` (launching `Task { await appState.sync() }`, updating track metadata, creating/reordering/modifying playlists, managing changelog events, and starting/adding/removing/reordering/ending/discarding live sessions) (`[TracksView.swift:TracksView.body]`, `[TrackDetailSheet.swift:TrackDetailSheet.body]`, `[PlaylistDetailView.swift:PlaylistDetailView.body]`, `[PlaylistsView.swift:CreatePlaylistSheet.body]`, `[PlaylistsView.swift:AddToPlaylistSheet.body]`, `[SyncQueueView.swift:SyncQueueView.body]`, `[LiveSetView.swift:LiveSetView.addTrackToSession(track:)]`, `[LiveSetView.swift:StartLiveSetSheet.body]`, `[LiveSetView.swift:EndLiveSetSheet.body]`).
- `SettingsSheet` reads and writes `TursoConfig.databaseURL` and `TursoConfig.authToken`, calls `TursoConfig.resetToDefaults()`, triggers `Task { await appState.sync() }`, and `SyncQueueView` reads `Bundle.main` `CFBundleShortVersionString` (`[SyncQueueView.swift:SettingsSheet.body]`, `[SyncQueueView.swift:appVersion]`).
- `LiveSetView` triggers `UIImpactFeedbackGenerator(.medium).impactOccurred()`, runs a 1.0-second `TimelineView(.periodic(from: .now, by: 1.0))`, schedules `DispatchQueue.main.asyncAfter(.now() + 0.3)` UI resets, updates `@FocusState`, and presents sheets/confirmation dialogs; `TrackDetailSheet` also schedules `DispatchQueue.main.asyncAfter` scroll animations (`[LiveSetView.swift:LiveSetView.haptic]`, `[LiveSetView.swift:LiveSetView.activeSessionView(session:)]`, `[LiveSetView.swift:LiveSetView.addTrackToSession(track:)]`, `[TrackDetailSheet.swift:TrackDetailSheet.body]`).
