# analytics_widgets

## Overview
Custom PySide6 `QWidget` data-visualization components for the Collection Analytics dashboard (`AnalyticsView`). The package exports five interactive, `QPainter`-rendered widgets consuming dataclasses and bracket definitions from `rekordbox_collection_manager.analytics` and colors/styles from `rekordbox_collection_manager.gui.theme`:

- `CamelotWheelWidget`: 24-sector concentric harmonic wheel (`1A`–`12A` inner minor ring, `1B`–`12B` outer major ring) with thermal track-density fills and live-play frequency rim overlays.
- `CrateHealthMatrixWidget`: 2D heatmap crossing `EXPOSURE_BRACKETS` and `PICK_RATE_BRACKETS` with dead-weight and peak zone indicators.
- `SurvivalDecayWidget`: Kaplan-Meier step-line unplayed-share decay curve with a configurable point-of-no-return threshold marker.
- `TransitionGraphWidget`: Directed track-transition network graph with connected-component spring-relaxation layout, interactive zoom/pan, and node dragging.
- `SetTurnoverWidget`: Multi-mode (`"cluster"`, `"turnover"`, `"retention"`) 100%-stacked session bar chart with archetype badges and exclusive mode controls.

## Invariants
- `[camelot_wheel_widget.py:CamelotWheelWidget.__init__]`, `[camelot_wheel_widget.py:CamelotWheelWidget.set_data]`: Enforces minimum widget size `(420, 420)`, coerces falsy `slices` to `{}`, and maintains scale maxima floors (`max_catalog_count >= 1`, `max_catalog_share >= 1.0`, `max_live_share >= 1.0`).
- `[camelot_wheel_widget.py:CamelotWheelWidget.paintEvent]`, `[camelot_wheel_widget.py:CamelotWheelWidget._get_sector_angles]`, `[camelot_wheel_widget.py:CamelotWheelWidget._get_slice_at_pos]`: Reserves `legend_space = 36.0`, aborts painting if `min(w, wheel_h) < 100`, positions 12 clockwise 30-degree sectors starting at 90 degrees (`"1B"`–`"12B"` outer, `"1A"`–`"12A"` inner), and rejects polar hit-tests outside `[r_inner, r_outer]`.
- `[camelot_wheel_widget.py:CamelotWheelWidget._get_slice_color]`, `[camelot_wheel_widget.py:CamelotWheelWidget._draw_slice]`, `[camelot_wheel_widget.py:CamelotWheelWidget._draw_legend_bar]`: Guards `track_count <= 0` / `max_catalog_count <= 0` to dark slate `QColor(24, 25, 33, 230)`, clamps normalized density `w` to `[0.0, 1.0]`, dims minor ring RGB by `0.88`, draws live rim arcs only when `live_share > 0`, and clamps legend width to `[180.0, 280.0]`.
- `[camelot_wheel_widget.py:CamelotWheelWidget.mouseMoveEvent]`, `[camelot_wheel_widget.py:CamelotWheelWidget.mousePressEvent]`: Tooltips and `slice_clicked` emissions occur only for non-`None` codes present in `self.slices` (and only on `Qt.MouseButton.LeftButton`).
- `[crate_health_widget.py:CrateHealthMatrixWidget.__init__]`, `[crate_health_widget.py:CrateHealthMatrixWidget.set_data]`, `[crate_health_widget.py:CrateHealthMatrixWidget.select_cell_by_name]`: Enforces minimum size `(480, 280)`, binds grid axes to `list(EXPOSURE_BRACKETS)` and `list(PICK_RATE_BRACKETS)`, coerces falsy `matrix` to `{}`, clamps `max_cell_count >= 1`, and catches `ValueError` to ignore unknown bracket names.
- `[crate_health_widget.py:CrateHealthMatrixWidget.paintEvent]`, `[crate_health_widget.py:CrateHealthMatrixWidget.mouseMoveEvent]`, `[crate_health_widget.py:CrateHealthMatrixWidget.mousePressEvent]`: Uses fixed margins (`left=120, bottom=44, top=24, right=20`) with `grid_w`/`grid_h >= 10`, clamps intensity to `[0.0, 1.0]`, classifies Death Zone (`"0% (Mai suonata)"` x `(">10 Set (Veterano)", "6-10 Set (Avanzato)")`) and Peak Zone (`("76-100%", "51-75%")` x `(">10 Set (Veterano)", "6-10 Set (Avanzato)")`), and relies on `paintEvent`-populated `_cell_rects` for hover and `LeftButton` selection.
- `[survival_widget.py:SurvivalDecayWidget.__init__]`, `[survival_widget.py:SurvivalDecayWidget.set_data]`, `[survival_widget.py:SurvivalDecayWidget.paintEvent]`: Enforces minimum size `(480, 260)`, defaults `point_of_no_return = 4`, coerces falsy `steps` to `[]`, clamps `max_set` to `1` if `0`, and draws the threshold marker only when `0 < point_of_no_return <= max_set`.
- `[survival_widget.py:SurvivalDecayWidget.mouseMoveEvent]`, `[survival_widget.py:SurvivalDecayWidget.mousePressEvent]`: Returns early when `steps` is empty, matches step nodes within squared distance `<= 144` (12 px radius), and emits `step_clicked` only on `LeftButton` while `hovered_step_idx` is not `None`.
- `[transition_graph_widget.py:TransitionGraphWidget.__init__]`, `[transition_graph_widget.py:TransitionGraphWidget.set_data]`, `[transition_graph_widget.py:TransitionGraphWidget._layout_nodes]`, `[transition_graph_widget.py:TransitionGraphWidget.resizeEvent]`: Enforces minimum size `(480, 320)`, resets `_has_custom_layout = False` in `set_data`, preserves manual node drags by skipping `_layout_nodes` when `_has_custom_layout` is `True`, runs 40 spring-relaxation iterations (`TARGET_DIST = 125.0`, `ideal_edge = 120.0`, decaying damping), and clamps `_default_zoom` to `[0.4, 1.0]`.
- `[transition_graph_widget.py:TransitionGraphWidget.wheelEvent]`, `[transition_graph_widget.py:TransitionGraphWidget.zoom_in]`, `[transition_graph_widget.py:TransitionGraphWidget.zoom_out]`: Clamps `_zoom_factor` to `[0.35, 4.5]`.
- `[transition_graph_widget.py:TransitionGraphWidget.paintEvent]`, `[transition_graph_widget.py:TransitionGraphWidget._draw_arrow]`, `[transition_graph_widget.py:TransitionGraphWidget._get_node_radius]`: Aborts graph painting when `nodes` or `edges` is empty, clamps node radius to `[13.0, 24.0]` and edge thickness to `[1.5, 6.0]`, skips arrows when center distance `< r1 + r2 + 6.0`, and truncates titles > 18 chars (`title[:16] + "…"`).
- `[transition_graph_widget.py:TransitionGraphWidget.mousePressEvent]`, `[transition_graph_widget.py:TransitionGraphWidget.mouseMoveEvent]`, `[transition_graph_widget.py:TransitionGraphWidget.mouseReleaseEvent]`: Floating toolbar button rects take click precedence over canvas drag/pan; node click/hover radii are `22` (`<= 484`) and `21` (`<= 441`) before edge midpoint hover `14` (`<= 196`); `node_clicked` emits only when drag squared distance `<= 16` (`not _node_moved`).
- `[turnover_widget.py:SetTurnoverWidget.__init__]`, `[turnover_widget.py:_TurnoverCanvas.__init__]`, `[turnover_widget.py:_TurnoverCanvas.set_mode]`: Enforces minimum sizes `(480, 280)` on `SetTurnoverWidget` and `(480, 240)` on `_TurnoverCanvas`, configures an exclusive `QButtonGroup` defaulting to `"cluster"`, and ignores modes outside `("cluster", "turnover", "retention")`.
- `[turnover_widget.py:_TurnoverCanvas.paintEvent]`, `[turnover_widget.py:_TurnoverCanvas.mouseMoveEvent]`, `[turnover_widget.py:_TurnoverCanvas.mousePressEvent]`: Clamps `grid_w`/`grid_h >= 10` and `col_w` to `[12.0, 50.0]`, renders empty-state text if `len(series) == 0`, switches X labels to `S{session_index}` when `n_sessions > 12`, uses `top_margin=38` in `mouseMoveEvent` vs `top_margin=52` in `paintEvent`, and emits `session_clicked` only on `LeftButton` when `hovered_session_idx` is not `None`.

## Side Effects
- `[camelot_wheel_widget.py:CamelotWheelWidget.__init__]`, `[crate_health_widget.py:CrateHealthMatrixWidget.__init__]`, `[survival_widget.py:SurvivalDecayWidget.__init__]`, `[transition_graph_widget.py:TransitionGraphWidget.__init__]`, `[turnover_widget.py:_TurnoverCanvas.__init__]`: Enable `setMouseTracking(True)` and configure widget minimum dimensions.
- `[camelot_wheel_widget.py:CamelotWheelWidget.*]`, `[crate_health_widget.py:CrateHealthMatrixWidget.*]`, `[survival_widget.py:SurvivalDecayWidget.*]`, `[transition_graph_widget.py:TransitionGraphWidget.*]`, `[turnover_widget.py:_TurnoverCanvas.*]`: Mutate internal widget display/selection/hover/layout state (`set_data`, `select_*`, `clear_selection`, `set_mode`, `reset_view`, `zoom_in`, `zoom_out`, mouse/wheel handlers), invoke `self.update()` to schedule Qt repaints, mutate cached hit-test geometry (`CrateHealthMatrixWidget._cell_rects`, `TransitionGraphWidget._btn_zoom_*`), update widget cursor (`PointingHandCursor`, `ClosedHandCursor`, `ArrowCursor`), paint UI graphics via `QPainter`, show/hide `QToolTip` popups via `QToolTip.showText`/`hideText`, and emit Qt signals (`slice_clicked`, `cell_clicked`, `step_clicked`, `edge_clicked`, `node_clicked`, `session_clicked`).
- `[turnover_widget.py:SetTurnoverWidget.__init__]`, `[turnover_widget.py:SetTurnoverWidget.set_data]`: Constructs child `QLabel`, `QButtonGroup`, `QPushButton`, and `_TurnoverCanvas` widgets with inline stylesheets and tooltips, wires signal connections, and delegates `set_data` to `self.canvas.set_data(series)`.
- `[turnover_widget.py:SetTurnoverWidget.select_session]`, `[turnover_widget.py:SetTurnoverWidget.clear_selection]`: Delegate to `self.canvas.select_session(session_idx)` and `self.canvas.clear_selection()`, which are not defined on `_TurnoverCanvas` (raising `AttributeError` if invoked).
