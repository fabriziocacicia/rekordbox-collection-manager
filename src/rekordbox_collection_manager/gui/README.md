# gui

## Overview
PySide6 desktop GUI layer for the Rekordbox Collection Manager application. The package coordinates dark-themed application startup (`app.py`, `macos.py`, `theme.py`, `assets.py`), the top-level 8-tab navigation shell (`MainWindow`), virtualized track/tag/playlist/history/play-count/replacement/analytics views, modal workflow dialogs (`CreatePlaylistDialog`, `CreateTagDialog`, `HistoryImportDialog`, `HistoryDiffDialog`, `TrackReplacementDiffDialog`, `RestoreDialog`, `TrackSearchDialog`, `TrackDetailDialog`), reusable interactive chip/table/filter widgets (`TracksTableWidget`, `EditableChipsContainer`, `MultiSelectSearchFilter`), custom analytics charts in [`analytics_widgets`](./analytics_widgets/README.md), and cooperative background worker threads (`workers.py`).

## Interface

### Subdirectories
- [`analytics_widgets`](./analytics_widgets/README.md): Interactive `QPainter`-rendered analytics chart widgets (`CamelotWheelWidget`, `CrateHealthMatrixWidget`, `SurvivalDecayWidget`, `TransitionGraphWidget`, `SetTurnoverWidget`, plus `COLOR_*` segment constants).

### Application Shell, Theme & Utilities
- `[__init__.py]`: Subpackage docstring only; defines no public symbols or `__all__`.
- `[app.py:parse_args]`, `[app.py:main]`: CLI argument parser (`-d` / `--db-path`) and desktop GUI entrypoint returning process exit code.
- `[assets.py:get_asset_path]`, `[assets.py:get_app_icon]`, `[assets.py:create_svg_icon]`, `[assets.py:get_refresh_icon]`, `[assets.py:get_database_pixmap]`, `[assets.py:get_database_icon]`: Bundle/local asset path resolution and dynamic SVG-to-`QPixmap`/`QIcon` rendering.
- `[macos.py:setup_macos_app_metadata]`, `[macos.py:update_macos_menu_title]`: macOS `darwin` process name, `NSBundle` display metadata, Dock icon, and top-level menu bar title setup.
- `[theme.py:FONT_FAMILY]`, `[theme.py:FONT_FAMILY_MONO]`, `[theme.py:COLOR_BG_DARK]`..`[theme.py:COLOR_RED_BORDER]`, `[theme.py:MODERN_DARK_QSS]`, `[theme.py:apply_dark_theme]`: Platform font stacks, dark color palette constants, global QSS stylesheet, and `apply_dark_theme(app: QApplication) -> None`.
- `[tree_utils.py:iter_tree_items]`, `[tree_utils.py:safe_clear_tree]`: Index-based `QTreeWidget` traversal and signal-safe clearing helpers.
- `[main_window.py:CollapsibleSidebarFrame]`, `[main_window.py:InfoView]`, `[main_window.py:MainWindow]`: Animated sidebar frame (`sidebarWidth` Qt property), read-only DB info view (`set_info`), and main application window with `open_history_session`, `open_playlist`, `open_tag`, `open_replace_file_for_track`, `toggle_sidebar`, `set_sidebar_collapsed`, `load_database`, `trigger_sync`, and `closeEvent`.

## Invariants
- `[main_window.py:MainWindow._on_nav_clicked]`, `[tracks_view.py:TracksView.confirm_unsaved_changes]`, `[playlists_view.py:PlaylistsView.confirm_unsaved_changes]`, `[tags_view.py:TagsView.confirm_unsaved_changes]`, `[history_view.py:HistoryView.confirm_unsaved_changes]`, `[history_detail_view.py:HistoryDetailView.confirm_unsaved_changes]`, `[play_count_view.py:PlayCountView.confirm_unsaved_changes]`, `[track_detail_view.py:TrackDetailView._confirm_unsaved_changes]`, `[track_table.py:TracksTableWidget.confirm_unsaved_changes]`: Tab switches, window close, search re-queries, tree switches, and detail navigation prompt `confirm_unsaved_changes()` whenever edits are staged and abort navigation on cancel.
- `[main_window.py:MainWindow.trigger_sync]`, `[analytics_view.py:AnalyticsView._create_rekordbox_playlist]`, `[playlists_view.py:PlaylistsView._delete_playlist_item]`, `[tags_view.py:TagsView._delete_tag_item]`, `[history_view.py:HistoryView._on_save_all_changes]`, `[play_count_view.py:PlayCountView._on_save_all_changes]`, `[replace_file_view.py:ReplaceFileView._on_execute_replace]`, `[track_detail_view.py:TrackDetailView._on_save_changes]`, `[track_table.py:TracksTableWidget.save_changes]`, `[create_playlist_dialog.py:CreatePlaylistDialog._on_submit]`, `[create_tag_dialog.py:CreateTagDialog._on_submit]`, `[history_import_dialog.py:HistoryImportDialog._on_execute_clicked]`, `[replacement_diff_dialog.py:TrackReplacementDiffView._on_confirm_clicked]`, `[restore_dialog.py:RestoreDialog._check_rekordbox_safety]`, `[restore_dialog.py:RestoreDialog._update_restore_button_state]`, `[restore_dialog.py:RestoreDialog._on_restore_clicked]`, `[workers.py:RestoreWorker]`, `[workers.py:DatabaseLoaderWorker]`: All database mutations, Turso cloud syncs, and DB restore operations block when `is_rekordbox_running()` returns `True` (and backup restore additionally requires explicit `QMessageBox.StandardButton.Yes` confirmation).
- `[main_window.py:MainWindow.load_database]`, `[main_window.py:MainWindow.trigger_sync]`, `[main_window.py:MainWindow._on_db_saved]`: At most one `_db_loader` runs at a time; background sync requests coalesce via `_sync_pending` (re-triggering with `create_backup=False`); startup sync runs once via `_initial_sync_done`; `db_saved` marks non-active views `{0, 1, 2, 4, 6}` dirty instead of interrupting active staged edits.
- `[workers.py:stop_worker]`, `[workers.py:wait_for_retired_workers]`, `[workers.py:TrackSearchWorker]`, `[workers.py:BackupWorker]`, `[workers.py:SyncWorker]`, `[workers.py:RestoreWorker]`: `stop_worker` disconnects `success`/`error`/`progress`, never force-terminates threads, and parks still-running threads in `_RETIRED_WORKERS`; `QThread` workers poll `isInterruptionRequested()` before work and signal emission (except `RestoreWorker`), while `BackupWorker` and `SyncWorker` run in daemon `threading.Thread`s (`SyncWorker` checks `isInterruptionRequested()` before emitting).
- `[main_window.py:MainWindow.closeEvent]`, `[analytics_view.py:AnalyticsView.cleanup]`, `[app.py:main]`: Window teardown stops `safety_timer`, invokes `cleanup()` on child views (`analytics_view` included) and `stop_worker(..., wait_ms=50)` on window workers, and drains retired workers with `wait_for_retired_workers` (`500` ms in `closeEvent`, `1000` ms after `app.exec()`).
- `[tracks_view.py:TracksView.populate_filter_options]`: In-memory SQLite engines (`:memory:`) execute filter-option queries synchronously rather than spawning `FilterOptionsWorker`.
- `[tracks_view.py:TracksView.update_limit_options]`, `[playlists_view.py:PlaylistsView.update_limit_options]`, `[tags_view.py:TagsView.update_limit_options]`: `limit_combo` is hidden with `"All Tracks"` (`userData=0`) when `total_tracks <= 2500`, and visible with 2500-step increments above `2500`.
- `[track_table.py:TracksTableModel.flags]`, `[track_table.py:TracksTableModel.data]`, `[track_table.py:TracksTableWidget._update_hover_state]`, `[track_table.py:TracksTableWidget._on_chip_item_added]`: Model items are non-editable (`ItemIsEnabled | ItemIsSelectable`), deduplicate tags/playlists preserving order, highlight staged rows, require Ctrl/Cmd (`ControlModifier | MetaModifier`) plus `enable_finder_clicks` for Finder link hover/click, and auto-evict `staged_edits` entries when tags/playlists match original sets.
- `[chip.py:BadgeChip.mousePressEvent]`, `[chip.py:EditableChipsContainer._add_single_item]`, `[chip.py:PlaylistChipsContainer.__init__]`, `[chip.py:TagChipsContainer.__init__]`, `[chip.py:DJChipsContainer.__init__]`: Unrecognized chip schemes fall back to `"teal"`; duplicate/empty items are rejected; `PlaylistChipsContainer` and `TagChipsContainer` set `allow_custom=False` (emitting `*_create_requested` for unmatched entries) whereas `DJChipsContainer` defaults `allow_custom=True`.
- `[history_view.py:HistoryView._refresh_table]`, `[history_detail_view.py:HistoryDetailView._on_data_loaded]`: Soft-deleted history sessions (`is_deleted=True`) disable inline title/location/DJ editing and display `Restore` instead of `Delete`.
- `[replace_file_view.py:FileDropZone.dragEnterEvent]`, `[replace_file_view.py:ReplaceFileView._on_track_selected_mode1]`, `[replace_file_view.py:ReplaceFileView._on_merge_tgt_selected]`: Mode 1 requires `is_replaceable_track` (MP3/AIFF) and a distinct `.aiff`/`.aif` replacement file; Mode 2 requires `is_replaceable_track` source, `is_aiff_track` target, and unequal track IDs.
- `[replacement_diff_dialog.py:calculate_metadata_diff]`, `[replacement_diff_dialog.py:DiffRowWidget.set_origin]`: `calculate_metadata_diff` omits Genre, BPM, and Musical Key from the 19 editable `"info"` fields, forces all 7 `"audio"` fields read-only to `"new"`, and enables editable/mergeable `"preservation"` fields only when `mode == "merge"`.
- `[history_diff_dialog.py:HistoryDiffDialog._set_table_row]`, `[history_import_dialog.py:HistoryImportDialog._on_execute_clicked]`: Current-origin history tracks cannot be toggled or excluded in `HistoryDiffDialog`; session merge actions map strictly to `"restore_and_merge"` (`is_current_deleted`), `"merge"` (`current_id`), or `"create_new"`.
- `[macos.py:setup_macos_app_metadata]`, `[macos.py:update_macos_menu_title]`, `[assets.py:get_asset_path]`: macOS metadata helpers no-op immediately when `sys.platform != "darwin"` and catch ctypes/Objective-C errors; `get_asset_path` searches `_MEIPASS`, package/repo `assets`, and `cwd` in fixed precedence.

## Side Effects
- `[app.py:main]`, `[macos.py:setup_macos_app_metadata]`, `[macos.py:update_macos_menu_title]`, `[theme.py:apply_dark_theme]`: Mutates global `QApplication` style/palette/QSS and `darwin` process/NSBundle/Dock/menu metadata via `ctypes` and Cocoa Objective-C runtime.
- `[main_window.py:MainWindow.__init__]`: Starts a 3000 ms polling `QTimer` (`safety_timer`) calling `is_rekordbox_running()`.
- `[tracks_view.py:TracksView.__init__]`, `[playlists_view.py:PlaylistsView.__init__]`, `[tags_view.py:TagsView.__init__]`, `[play_count_view.py:PlayCountView.__init__]`, `[replace_file_view.py:ReplaceFileView.__init__]`, `[multi_select_filter.py:MultiSelectPopup.__init__]`, `[track_search_dialog.py:TrackSearchDialog._init_ui]`, `[history_view.py:LocationDelegate.createEditor]`: Starts 60–250 ms single-shot debounce timers across search inputs and schedules `QTimer.singleShot(0, ...)` for inline location completer popups.
- `[workers.py:*]`: Spawns `QThread` and daemon `threading.Thread` workers to read/write the Rekordbox SQLite database (`open_database`, track/tag/playlist/history/play-count queries & mutations, `cleanup_duplicate_song_tags` on DB load when Rekordbox is closed, audio file inspection/replacement/trash/backup/move, database backup & restore on disk, and Turso HTTP cloud sync + local sync-state persistence).
- `[analytics_view.py:AnalyticsView._export_m3u8]`, `[analytics_view.py:AnalyticsView._export_xml]`, `[analytics_view.py:AnalyticsView._create_rekordbox_playlist]`, `[analytics_view.py:AnalyticsView._on_analytics_error]`: Prompts via `QFileDialog`/`QMessageBox`, writes `.m3u8` or Rekordbox XML files to disk, creates a purge playlist in the Rekordbox database, and displays error warning dialogs only on interactive refreshes (`_interactive_refresh=True`).
- `[track_table.py:TracksTableWidget.open_folder]`, `[track_table.py:TracksTableWidget.reveal_file]`, `[track_table.py:TracksTableWidget.copy_tracklist_to_clipboard]`, `[track_detail_view.py:TrackDetailView._on_open_folder]`, `[track_detail_view.py:TrackDetailView._on_reveal_file]`, `[track_detail_view.py:TrackDetailView._on_copy_path]`, `[play_count_view.py:PlayCountView._on_table_context_menu]`, `[main_window.py:MainWindow._on_reveal_backups_in_finder]`: Invokes OS file manager (`open_in_folder`, `reveal_in_file_manager`), creates backup directories (`mkdir(parents=True, exist_ok=True)`), and writes text to `QApplication.clipboard()`.
- `[assets.py:get_app_icon]`, `[track_detail_view.py:TrackDetailView._load_artwork]`, `[replace_file_view.py:ReplaceFileView._on_track_selected_mode1]`, `[replacement_diff_dialog.py:calculate_metadata_diff]`, `[restore_dialog.py:RestoreDialog.reload_backups_list]`: Reads icons, artwork images, file sizes, and backup snapshots from the local filesystem.
- `[history_diff_dialog.py:HistoryDiffDialog._open_track_search]`: Mutates caller-provided `current_track_index` dictionaries and `TrackDiffItem` objects in place.
- `[tree_utils.py:safe_clear_tree]`, `[chip.py:EditableChipsContainer.set_items]`, `[track_detail_view.py:TrackDetailView._populate_chips]`, `[history_detail_view.py:HistoryDetailView._render_djs]`: Removes child widgets/items and schedules Qt object destruction via `deleteLater()`.
