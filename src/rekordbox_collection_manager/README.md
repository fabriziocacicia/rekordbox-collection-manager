# rekordbox_collection_manager

## Overview
Core Python package for inspecting, curating, backing up, syncing, and analyzing Rekordbox collections (`master.db` SQLCipher and `exportLibrary.db`), providing headless domain APIs, interactive CLI tools, a macOS `launchd` background sync daemon, and the nested [`gui`](./gui/README.md) PySide6 desktop application.

## Invariants
- **Version resolution (`__init__.py`)**: `[__init__.py:_get_version]` reads `[project].version` from `pyproject.toml` when running on Python `>= 3.11` and the file exists; otherwise falls back to `importlib.metadata.version("rekordbox-collection-manager")` and finally `"0.2.0"`.
- **Process safety (`utils.py`, CLIs, `backup_restore.py`, `turso_sync.py`)**:
  - `[utils.py:is_rekordbox_running]` ignores the current PID and processes containing `"rekordbox-collection"`; `[utils.py:ensure_rekordbox_not_running]` aborts mutations unless `force=True`.
  - `[backup_restore.py:create_database_backup]` and `[backup_restore.py:perform_restore]` raise `RuntimeError` if `is_rekordbox_running()` and `not force`; `[turso_sync.py:run_sync_cycle]` refuses sync under the same condition; `[edit_play_count.py:main]`, `[rename_history.py:main]`, and `[replace_file.py:main]` enforce `[utils.py:ensure_rekordbox_not_running]`.
- **Database opening & file I/O (`utils.py`)**:
  - `[utils.py:open_database]` configures `NullPool` with `timeout=30.0` and probes `DEVICE_LIBRARY_PLUS_KEY`, `master_key`, or plaintext based on whether `"export"` appears in the filename.
  - `[utils.py:resolve_exact_disk_path]`, `[utils.py:safe_unlink_file]`, `[utils.py:safe_rename_file]`, and `[utils.py:safe_move_file]` handle macOS NFC/NFD normalization mismatches by retrying `ENOENT` against exact disk entries and NFD/NFC variants.
- **Analytics rules (`analytics.py`)**:
  - `[analytics.py:normalize_to_camelot]` matches `^0?([1-9]|1[0-2])([ABab])$` or `[analytics.py:TRADITIONAL_KEY_TO_CAMELOT]`, returning `("", "", 0, "")` for empty/null keys and `("", "", 0, k)` for unknown keys.
  - `[analytics.py:parse_session_datetime]` uses `datetime(1970, 1, 1, 0, 0, 0)` as a fallback sentinel; `[analytics.py:compute_analytics]` treats `dt.year <= 1970` as unrecorded (`date_added_str == ""`, exposure anchored to `first_played_session_idx` or `0`), excludes soft-deleted (`rb_local_deleted`) and streaming (`build_exclude_streaming_clause`) rows, scales `BPM > 1000` by `/ 100.0`, filters gigs by `(t_count >= min_session_tracks) and (dur >= min_session_duration_sec or dur == 0)` sorted ascending by `(date_dt, session_id)`, computes `burnout_threshold` as `10` if no track has `dj_play_count > 0` else `max(5, play_counts_nonzero[idx_p])` at `burnout_percentile`, clamps played track starts to `<= first_played_session_idx`, and assigns one mutually exclusive cluster in order (`In Incubazione / Untested`, `Burnout Tracks`, `Peak Bangers`, `Core Rotation`, `Deep Cuts / Occasionals`, `Dead Weight (Zavorra)`, `Standard`).
  - `[analytics.py:compute_analytics]` requires `exposure_gigs >= 1` for `health_matrix`, always seeds all 24 keys (`1A`–`12B`) in `camelot_slices`, enforces point-in-time causality on `turnover_series` (`stagnation_risk = True` iff `len >= 3` and last-3 mean `new_entries_pct < 15.0`), builds `survival_curve` over `0..min(20, num_valid_sessions)` with `k=0 -> 100.0%` (`point_of_no_return_set` first `k >= 3` with `prev_pct - unplayed_pct < 2.0`, fallback `min(4, max_k)` or `4`), and drops self-transitions and edges below `transition_min_frequency` in `transition_edges`.
  - `[analytics.py:classify_session_archetype]` evaluates `Genesis / Battesimo`, `Twin / Serata Fotocopia`, `Testing Lab / Rodaggio`, `Prime-Time / Festival`, `Digger's Set / Ricerca`, and `Signature Flow / Equilibrato` in order; `[analytics.py:export_tracks_to_rekordbox_xml]` prefixes non-`file://` paths with `file://localhost`; `[analytics.py:create_purge_playlist_in_rekordbox]` writes 1-based `TrackNo` with monotonic integer IDs above `MAX(CAST(ID AS INTEGER))` (fallback `100000`).
- **Backup, restore & daemon (`backup_restore.py`, `daemon.py`)**:
  - `[backup_restore.py:create_database_backup]` raises `FileNotFoundError` if `target_db` is missing; `[backup_restore.py:perform_restore]` requires a directory containing `Pioneer_Library/master.db`, `master.db`, or `exportLibrary.db`, creates a `rekordbox_pre_restore_safety_{timestamp}` backup first, and verifies `master.db`/`exportLibrary.db` exist after restore; `_sync_copy` and `_sync_replace` treat `rsync` exit codes `0`, `23`, and `24` as non-fatal; `[backup_restore.py:list_backups]` sorts newest-first.
  - `[daemon.py:RekordboxAppObserver]` triggers only when `"rekordbox"` is in lowercased `localizedName()` and `"rekordbox-collection"` is absent; `[daemon.py:run_daemon_loop]` throttles Turso `PENDING` changelog polling to `30s` and syncs only while Rekordbox is stopped (restoring the `SIGINT` handler on exit); `[daemon.py:install_launchd_service]` enables `RunAtLoad` and `KeepAlive`.
- **Track querying, playlists & tags (`edit_play_count.py`, `playlists.py`, `tags.py`, `utils.py`)**:
  - `[utils.py:is_purchased_path]` matches directory segment `"purchased"` case-insensitively; `[edit_play_count.py:search_tracks]` inspects `PRAGMA table_info`/`sqlite_master`, filters `rb_local_deleted` and `p.Attribute = 0`, scales positive `bpm_min`/`bpm_max` by `* 100`, enforces `play_col >= 3` for `purchased_filter in ("purchasable", "buyable")`, and skips streaming exclusion when `content_id` is explicitly provided.
  - `[edit_play_count.py:update_track_play_count]`, `[edit_play_count.py:set_track_play_count]`, and `[edit_play_count.py:batch_update_track_play_counts]` clamp play counts `>= 0` and prefer `DJPlayCount` over `PlayCount`.
  - `[playlists.py:parse_smartlist_to_sql]` returns `("1=1", {})` on empty input, parse errors, or zero conditions, uses `OR` only for `LogicalOperator="2"` (otherwise `AND`), resolves signed/unsigned 32-bit `myTag` IDs, and scales BPM values `< 500` by `* 100.0`; `[playlists.py:create_playlist]` and `[tags.py:create_tag]` validate non-empty names, active parents, and uniqueness (`ValueError`), assigning unique random IDs in `[100_000_000, 2_147_483_647]` plus `MAX(Seq)+1` (or reactivating soft-deleted rows); `[playlists.py:delete_playlist]` and `[tags.py:delete_tag]` reject non-empty targets (`ValueError`) and return `True` if already `rb_local_deleted == 1`; `[tags.py:fetch_tags_tree]`, `[tags.py:fetch_tag_tracks]`, and `[edit_play_count.py:add_track_to_tag]` match signed/unsigned 32-bit tag IDs via `[utils.py:resolve_tag_matching_ids]`.
- **History & external history merge (`rename_history.py`, `history_import.py`, `utils.py`)**:
  - `[utils.py:parse_history_name]` parses `<Base Name> [@ <Location>] [w <Artist(s)>]`; `[rename_history.py:realign_history_order]` assigns contiguous 1-based `Seq` values per active parent (`'root'` / year / month); `[rename_history.py:ensure_djmd_history_folders]` uses `ID=str(year)` and `ID=f"{year}{month:02d}"`; `[rename_history.py:soft_delete_history_session]` and `[rename_history.py:restore_history_session]` are idempotent via `rb_local_deleted`, clamp `DJPlayCount >= 0`, and cascade-hide empty month/year folders on delete; `[rename_history.py:fetch_session_tracks]` includes deleted `djmdSongHistory` rows only when the parent session has `rb_local_deleted == 1`.
  - `[history_import.py:match_track_to_current]` resolves matches strictly in priority order (`by_id` -> `by_filename` -> `(title, artist)` -> `(title, duration)` with `+/-2s` tolerance); `[history_import.py:analyze_external_history_db]` filters `Attribute=0` and classifies `'new'`, `'in_trash'`, `'to_merge'`, or `'identical'`; `[history_import.py:calculate_history_session_diff]` sets `'matched'` (`included=False`), `'new'`, or `'missing_file'`, sorting merged items by `(played_at or '9999', track_no)` and renumbering `1..N`; `[history_import.py:execute_history_merge_plan]` runs inside a single `current_engine.begin()` transaction, regenerates UUIDs on collision, and calls `realign_history_order` after commit.
- **File replacement & track merge (`replace_file.py`, `utils.py`)**:
  - `[replace_file.py:inspect_audio_file]` checks disk existence and parses metadata with `mutagen` plus a binary AIFF/AIFC `COMM` chunk fallback; `[replace_file.py:trash_file_macos]` uses macOS Finder Trash on `darwin` or `.bak` rename elsewhere; `[replace_file.py:replace_track_audio_file]` requires an existing AIFF replacement file and a distinct MP3/AIFF target track, resets analysis flags, and rolls back moved/renamed files if the DB transaction fails; `[replace_file.py:merge_imported_tracks]` requires distinct MP3/AIFF source and AIFF target tracks, deduplicates playlists/tags and cues within `100ms` on `'merge'`, strips `'genre'/'bpm'/'key'` before applying metadata, and generates unused 28-bit numeric entity IDs `>= 100` (repairing UUID entity IDs via `[replace_file.py:repair_uuid_entity_ids]`); `[utils.py:install_rekordbox_artwork]` requires `len(track_uuid.strip()) >= 4` and generates `artwork.jpg`, `artwork_m.jpg` (`240x240`), and `artwork_s.jpg` (`80x80`).
- **Turso cloud sync (`turso_sync.py`)**:
  - `[turso_sync.py:get_turso_credentials]` reads environment variables or `.env` and rewrites `libsql://` to `https://`; `[turso_sync.py:TursoHttpClient]` calls `{url}/v2/pipeline` with a `30s` timeout and raises `RuntimeError` on HTTP `!= 200` or server error payloads; `[turso_sync.py:export_collection_to_turso]` closes the SQLite connection before sending HTTP batches (`100`–`300` statements) and checks `cancel_fn`; `[turso_sync.py:apply_changelog_events]` applies 12 whitelisted mobile action types inside one `engine.begin()` transaction and updates Turso changelog statuses (`'PROCESSED'`/`'FAILED'`) only after releasing the SQLite write lock; `[turso_sync.py:run_sync_cycle]` skips export and backup when `not force`, `pending == 0`, and `sync_state.json` matches `db_path`, `mtime`, and `size`.

## Side Effects
- **Import & filesystem reads (`__init__.py`, `analytics.py`, `utils.py`)**: `[__init__.py:__version__]` reads `pyproject.toml` or queries `importlib.metadata` at import time; `[daemon.py]` configures `logging.basicConfig(INFO)` at import time; read queries across `analytics.py`, `edit_play_count.py`, `playlists.py`, `tags.py`, `rename_history.py`, and `history_import.py` open SQLite/SQLCipher connections (`open_database` / `engine.connect()`).
- **Database mutations**:
  - `[analytics.py:create_purge_playlist_in_rekordbox]`, `[playlists.py:create_playlist]`, `[playlists.py:delete_playlist]`, and `[edit_play_count.py:add_track_to_playlist]` / `remove_track_from_playlist` write `djmdPlaylist` and `djmdSongPlaylist`.
  - `[tags.py:create_tag]`, `[tags.py:delete_tag]`, `[tags.py:sort_tags_in_folder]`, `[tags.py:cleanup_duplicate_song_tags]`, and `[edit_play_count.py:add_track_to_tag]` / `remove_track_from_tag` mutate `djmdMyTag` and `djmdSongMyTag`.
  - `[edit_play_count.py:update_track_play_count]` / `set_track_play_count` / `batch_update_track_play_counts` and `[utils.py:update_track_comment]` write `djmdContent` / `content`.
  - `[rename_history.py:realign_history_order]` / `ensure_djmd_history_folders` / `soft_delete_history_session` / `restore_history_session` / `update_history_record` / `batch_update_history_records` and `[history_import.py:execute_history_merge_plan]` write `djmdHistory`, `djmdSongHistory`, and `djmdContent` (and legacy `history`/`songHistory`/`content` tables).
  - `[replace_file.py:replace_track_audio_file]`, `[replace_file.py:merge_imported_tracks]`, and `[replace_file.py:repair_uuid_entity_ids]` update `djmdContent`, `agentRegistry`, `djmdArtist`, `djmdAlbum`, `djmdGenre`, `djmdLabel`, `djmdSongHistory`, `djmdSongPlaylist`, `djmdSongMyTag`, and `djmdCue`, soft-deleting merged source tracks (`rb_local_deleted = 1`).
- **Disk, OS, process & GUI effects (`analytics.py`, `backup_restore.py`, `daemon.py`, `replace_file.py`, `turso_sync.py`, `utils.py`, CLIs)**:
  - `[analytics.py:export_tracks_to_m3u8]` and `[analytics.py:export_tracks_to_rekordbox_xml]` write UTF-8 playlist/XML files on disk.
  - `[backup_restore.py:create_database_backup]` and `[backup_restore.py:perform_restore]` create backup/safety directories, copy `-wal`/`-shm` files, delete stale WAL/SHM files on restore, and execute `rsync` subprocesses (or `shutil.copytree`/`copy2`/`rmtree`).
  - `[replace_file.py:replace_track_audio_file]`, `[replace_file.py:merge_imported_tracks]`, `[replace_file.py:trash_file_macos]`, and `utils.py` disk helpers move, rename, or unlink audio files, invoke `osascript` to move files to macOS Finder Trash (or rename `.bak`), launch file managers via `subprocess.Popen` (`open`/`explorer`/`xdg-open`), write cached artwork to `~/.cache/rekordbox-collection-manager/artwork_cache`, and write `artwork.jpg`, `artwork_m.jpg`, and `artwork_s.jpg` under `PIONEER/Artwork`.
  - `[daemon.py:run_daemon_loop]`, `[daemon.py:install_launchd_service]`, and `[daemon.py:uninstall_launchd_service]` register `NSWorkspace` observers and `SIGINT` handlers, write `LAUNCHD_PLIST_PATH`, and execute `launchctl load`/`unload` subprocesses.
  - `[turso_sync.py]` reads `.env`, reads/writes `~/.config/rekordbox-collection-manager/sync_state.json`, sends HTTP `POST` requests to Turso (`/v2/pipeline`), creates/mutates 7 remote tables and 9 indexes, and triggers local `master.db` writes plus `[backup_restore.py:create_database_backup]`.
  - CLI entry points (`[edit_play_count.py:main]`, `[rename_history.py:main]`, `[replace_file.py:main]`, `[daemon.py:main]`) read terminal prompts via `questionary`, write stdout/logs, may mutate `sys.path` under `__main__`, and exit via `sys.exit`; [`gui`](./gui/README.md) launches the interactive PySide6 event loop and spawns background workers (`QThread` and daemon `threading.Thread`) wrapping these core operations.
